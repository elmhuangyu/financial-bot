# Interactive HTML Dashboard Generator Skill

This skill guides the agent in building an interactive, dark-themed, single-page HTML financial dashboard on-demand based on whatever financial reports, projections, and CSV deliverables were generated during the session.

---

## 1. Core Operating Principles

1. **On-Demand / Opt-In Only**:
   - HTML dashboards are **never generated by default**. Standard runs only produce deterministic Markdown reports (`data/output/<name>_report.md`) and structured CSV files (`data/output/<name>.csv`).
   - Only activate this skill when the user explicitly requests an HTML report, web view, or visual dashboard.
2. **Dynamic & Agnostic Input Handling**:
   - **Do NOT assume a fixed schema or fixed set of reports.** The session deliverables may represent Asset Allocation, Brinson Attribution, Retirement Projections, Budget Tracking, Tax Optimization, or Real Estate models.
   - Inspect whatever deliverables exist in `data/output/` (CSV tables, metrics, markdown findings) and dynamically tailor the dashboard's tabs, KPI cards, charts, and data tables to match.
3. **Zero Backend / 100% Self-Contained**:
   - Must run completely offline in any standard browser without local web servers.
   - Embed all parsed session metrics and tables as client-side JSON (`const APP_DATA = { ... };`).
4. **Zero Absolute Paths**:
   - Never embed system root paths or file URI schemes.

---

## 2. Design System & Tech Stack (Zero-Build CDN)

- **Styling**: Tailwind CSS CDN (`<script src="https://cdn.tailwindcss.com"></script>`).
- **Visualizations**: Chart.js v4 CDN (`<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>`).
- **Icons**: Lucide Icons CDN (`<script src="https://unpkg.com/lucide@latest"></script>`).
- **Theme Canvas**: Modern Dark Financial Slate (`bg-slate-950`, text in `text-slate-100` / `text-slate-400`).
- **Glassmorphism Panels**: `glass-panel` class:
  ```css
  .glass-panel {
      background: rgba(15, 23, 42, 0.75);
      backdrop-filter: blur(12px);
      border: 1px solid rgba(51, 65, 85, 0.5);
  }
  ```
- **Typography**: Clean sans-serif for UI labels; monospace (`font-mono`) for monetary amounts, percentages, and tickers.

## 3. Standard UI Modules & Interactivity Features

### 3.1 Global Header & Controls
- **Branding & Context**: Title of the analysis, active analysis pill badge, statement/data as-of timestamp.
- **Privacy Mode Toggle (Hide / Show Balances)**:
  - Button with Lucide `eye` / `eye-off` icon toggle.
  - When enabled: Masks sensitive dollar figures and share quantities across KPI cards, breakdown labels, and table cells as `••••••` or `***`.
  - Retains percentages, weights, and risk ratios visible for safe sharing/screenshotting.
- **Dual-Currency Switcher (when multi-currency is relevant)**:
  - Segmented toggle between USD ($) and CAD (C$) with real-time conversion.

### 3.2 Top KPI Summary Cards
- Prominently display the 3 to 5 most important high-level figures for the current session (e.g., Net Worth, Total Savings Rate, Portfolio Alpha/Return, Downside Sortino, FI/Retirement Date).

### 3.3 Dynamic Multi-Tab Navigation
Organize dense analysis into clean, dedicated tabs matching the session's active deliverables, e.g.:
- **Tab 1: Overview & Allocation** (Visual charts for asset mix, accounts, tax buckets, sectors).
- **Tab 2: In-Depth Analytics** (Attribution waterfall, factor risk matrix, Monte Carlo simulation curves, or cash flow projections).
- **Tab 3: Interactive Data Explorer / Grid** (Holdings, transactions, or cash flow schedules).

### 3.4 Interactive Data Explorer (Grid / Table)
When presenting underlying holdings or transaction lists:
- **Cross-Account Asset Aggregation (`Aggregate Assets` toggle)**:
  - Consolidates positions sharing the same symbol/asset across multiple accounts into a single merged row.
  - Aggregates quantity, market value, cost basis, and unrealized P&L.
  - Displays multi-account badges (e.g., `2 Accounts`) and aggregated tax statuses.
- **Real-Time Search Bar**: Instant keyword filter across symbol, description, sector, account.
- **Dynamic Dropdown Filters**: Multi-field filters for Owner, Tax Treatment, Category, etc.
- **Column Sorting**: Interactive ascending/descending sort on header clicks.
- **Reactive Summary Footer**: Live total counts, aggregate market values, and net totals for currently filtered rows.

## 4. Execution Workflow (Step-by-Step SOP)

1. **Inspect Available Session Deliverables**:
   - Check `data/output/` for all CSV files (e.g. `normalized_holdings.csv`, `performance_attribution_*.csv`, `projections_*.csv`) and Markdown reports.
2. **Draft Ad-Hoc HTML Generator Script in `data/tmp/`**:
   - Write `data/tmp/generate_html_report.py`.
   - Ingest session CSVs and summarize key metrics into an `APP_DATA` JSON payload.
   - Assemble the HTML template adhering to the Design System, Privacy Mode, Aggregation toggle, and Chart.js modules.
3. **Execute & Generate**:
   - Run: `uv run python data/tmp/generate_html_report.py`
   - Output to `data/output/index.html` (and `data/output/<report_name>.html`).
4. **Verify Quality**:
   - Verify zero absolute path references.
   - Run `just lint` to confirm formatting and path cleanliness.
