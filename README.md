`financial-bot` is a helper system designed to assist users in organizing their financial situations and generating personalized financial advice (e.g., retirement planning, budget analysis, and expense tracking). 

Instead of running as a traditional standalone application, this project relies on an external AI Agent (such as **Antigravity CLI**, **Codex**, or **Claude Code**) to orchestrate the workflow, generate custom analysis scripts, and execute them.

---

## How It Works & Workflow

This project leverages the power of AI agents to dynamically interact with code and data. The lifecycle of a user query follows this workflow:

1. **Agent Integration**: The user interacts with this project through an AI Agent (e.g., `antigravity`, `claude-code`, etc.).
2. **Instruction Loading**: The AI Agent reads [AGENTS.md](AGENTS.md) located at the project root. This file contains prompt templates and specific guidelines on how to process the user's financial statements and data.
3. **Dynamic Script Generation**: Based on [AGENTS.md](AGENTS.md) and the user's prompt, the AI Agent generates ad-hoc Python scripts to parse statement files (CSV, PDF, etc.) and perform data analysis.
4. **Temporary Execution**: These ad-hoc scripts are stored in [src/tmp/](src/tmp/) and executed on the fly by the AI Agent to process the user's data.
5. **Report Generation**: The Agent compiles the parsed results and outputs a detailed financial report in Markdown format according to the user's requirements.
6. **Code Promotion (Permanent Code)**: Frequently used ad-hoc scripts or generic helpers in [src/tmp/](src/tmp/) are promoted, refactored, and rewritten into permanent, reusable modules in [src/core/](src/core/).

## Getting Started & Usage

### Prerequisites

This project manages its Python environment and dependencies using `uv`. 

1. Install `uv` if you haven't already:
   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```
2. Set up the environment and install dependencies:
   ```bash
   uv sync
   ```

### Running the Bot

You do not run this bot directly using `uv` or python commands. Instead, you point your favorite AI Agent to this directory. 

For example, when using an agent like **Antigravity CLI** or **Claude Code**:
1. Open a terminal in the project root.
2. Launch your AI agent.
3. Instruct the agent:
   > *"Read AGENTS.md, analyze the bank statements in my local folder, and write a retirement savings report in markdown."*
4. The agent will read [AGENTS.md](AGENTS.md), automatically generate the required scripts under [src/tmp/](src/tmp/), execute them to parse the statements, and output your report.
